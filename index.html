Support for this Project has Ended

Why we're saying goodbye:

We have not ended support for this project because we can no longer maintain it. We have ended support for this project because
the school employs a much more difficult and complex type of site blocking than we originally realized. We can no longer maintain
this project due to the fact that, no matter how hard we try, we can't get this website unblocked. And maintaining something that
doesn't serve it's designated purpose is not why we exist.

What this means for US:

We have shifted focus towards developing other services and a public version of this game site to release onto the internet. If anyone
has their own non-school issue device and would like to test the new site and other future projects, please reach out to us.

What this means for YOU:

This means we will no longer be able to provide a stable gaming experience. Anyone who used this website can now access another game site
not developed by us. You can access it at: https://sites.google.com/sfps.k12.nm.us/math-marathon/games
